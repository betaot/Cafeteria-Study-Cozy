# ☕ Cafeteria Study Cozy

Um projeto web responsivo e multipágina desenvolvido para simular o ambiente institucional de uma cafetaria moderna, focada em produtividade e conforto para estudantes e profissionais.

## 📌 Sobre o Projeto
O "Study Cozy" foi criado com o objetivo de consolidar conhecimentos práticos em desenvolvimento Front-End, com foco absoluto em estruturação semântica e layouts modernos sem a utilização de frameworks externos. O site simula uma experiência completa de navegação, desde a apresentação do espaço até à visualização do cardápio e contacto.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica profunda (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Estilização pura.
  * **Flexbox:** Construção de grelhas responsivas, alinhamento de componentes e implementação do padrão "Sticky Footer".
  * **Media Queries:** Adaptação fluida do layout para dispositivos móveis (`@media`).
  * **Variáveis de Cor (Paleta):** Utilização consistente de tons inspirados em café (Bege `#F5F0EA`, Castanho `#3E2723`, Caramelo e Oliva).
* **Tipografia:** Integração com Google Fonts (Playfair Display para títulos, Montserrat para textos).

## ⚙️ Funcionalidades e Estrutura
O projeto é composto por 4 páginas interligadas:
1. **Home (`index.html`):** Secção "Hero" de alto impacto com imagem de fundo e call-to-action.
2. **Sobre (`sobre.html`):** Layout em grelha alternada (imagem/texto) desenhado com Flexbox.
3. **Cardápio (`cardapio.html`):** Exibição de produtos em formato de "Cards" com efeitos de transição (hover) e sombras (box-shadow).
4. **Contato (`contato.html`):** Formulário interativo e dividido no ecrã (Split-screen) com campos estilizados e bloqueio de redimensionamento indesejado no `textarea`.

## 🛠️ Como Executar
Sendo um projeto estático, não requer instalação de pacotes ou servidores complexos:
1. Faça o clone deste repositório ou descarregue os ficheiros.
2. Abra o ficheiro `index.html` em qualquer navegador web moderno (Chrome, Firefox, Edge, Safari).
